АТЛАС МАТЕРИАЛОВ — КАК ДОБАВИТЬ СВОИ ФОТО

1. Откройте папку images/materials.
2. Сохраните фотографии в формате JPG (лучше 2000–3000 px по длинной стороне).
3. Назовите каждый файл ТОЧНО так, как указано ниже.
4. Положите все файлы в images/materials. Не создавайте дополнительные папки.
5. Загрузите на GitHub всю папку проекта целиком: index.html + images + этот файл.
6. GitHub Pages откроет index.html, а локальные фотографии загрузятся из images/materials.

Важно: не нужно редактировать HTML или вставлять ссылки. Просто заменяйте файлы фотографиями с такими же именами.
Если фотография ещё не добавлена, на её месте будет показана подсказка с именем нужного файла.
